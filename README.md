# Auto_Set 
*Pour des contrôles sans technique*  

## 📖 Description du projet  
**Auto_Set** est une plateforme de mise en relation entre **clients** et **professionnels dans le domaine de la réparation automobile**.  
L’objectif est de proposer une solution **simple**, **efficace** et **performante** pour faciliter :  
- Le retour simple de votre contrôle technique.  
- La prise de rendez-vous pour votre véhicule.

Le projet est en **développement continu** : des mises à jour régulières viendront enrichir ses fonctionnalités et améliorer l’expérience utilisateur.  

---

## 🚀 Fonctionnalités prévues  
- ✔️ Mise en relation clients ↔ professionnels  
- ✔️ Interface intuitive et responsive  
- ✔️ Gestion des profils utilisateurs  
- ✔️ Base de données pour gérer les clients,professionnel,,véhicule,controle technique,agendas
- ✔️ Mises à jour régulières avec des nouvelles fonctionnalités

## 📦 Installation & Utilisation  

1. **Cloner le projet**  
```bash
git clone https://github.com/ton-compte/Auto_Set.git
```

2. **Accéder au dossier du projet**
```bash
cd Auto_Set
```

3. **Accéder à la bdd du projet**
```bash
mysql -h 172.16.101.235 -u auto_set -p
```

3. **Lancer le projet**

Ouvrir le fichier index.html dans un navigateur.
